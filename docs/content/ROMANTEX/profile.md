# Perfil del proyecto

## Tema
Digitalización del inventario (rollos/metraje residual) y estandarización de fichas técnicas mínimas de producto en Romantex S.A.C.

## Descripción
PoC académico (1 semestre) para showroom/almacén Lima: visibilidad de metros residuales por variante, ficha técnica mínima y alertas de mínimo. Romantex es referente y sujeto real (telas/decoración); el PoC no reemplaza ERP textil ni afirma partnership de implementación productiva.

**Nota de corrección:** el planteamiento inicial “calzado + tallaje” se descartó porque Romantex no fabrica ni vende calzado.

## Problema identificado
**Hipótesis:** la promesa de stock amplio y entrega inmediata puede degradarse si el metraje residual por rollo/variante no es consultable de forma única. No es auditoría AS-IS interna. Se estandariza ficha operativa mínima (código, color, ancho, metros residuales, ubicación), distinta del PDF técnico de proveedor/contract.

## Alcance
MVP 1: 1 sede, 1 familia stock, 50–100 SKUs/rollos, modelo rollo→metros, ficha mínima, alertas, CSV. Fuera: EDI, RFID, e-commerce, ERP textil, calzado.
