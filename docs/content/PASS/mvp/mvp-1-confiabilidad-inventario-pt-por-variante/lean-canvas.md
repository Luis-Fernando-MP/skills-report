# Lean Canvas - MVP 1

| Bloque | Descripción |
|---|---|
| **1. Problema** | - Inconsistencia entre disponibilidad comercial y stock físico. `evidencia`
- Proceso de consulta de stock lento e ineficiente. `hipótesis`
- Pérdida de ventas por falta de información precisa. `hipótesis`
**Alternativas existentes:** Consultas telefónicas al almacén, revisión manual de cuadernos/Excel desactualizados. |
| **2. Segmentos de Clientes** | **Early adopters:**
- **Equipo comercial:** Necesita información precisa y rápida para confirmar pedidos.
- **Almaceneros/Operarios de planta:** Requieren una herramienta sencilla y confiable para registrar movimientos de inventario. |
| **3. Propuesta de Valor Única (UVP)** | Para **comerciales y almaceneros de Calzados Romantex S.A.C.** que **sufren la inconsistencia de inventario de producto terminado**, el **piloto de inventario PT por variante en Google Sheets** es una **solución de registro y consulta de stock en ≤2 ubicaciones propias** que **asegura la confiabilidad del dato al cierre de turno**, a diferencia de **procesos manuales desorganizados**. |
| **4. Solución** | **Features principales:**
1.  **Maestro de Variantes:** Centraliza SKU, modelo, color, talla.
2.  **Bitácora de Movimientos:** Registro de entradas, salidas, traslados, ajustes por almacenero.
3.  **Consulta Rápida:** Interfaz para que el comercial obtenga disponibilidad por variante. |
| **5. Canales** | **Comunicación y Distribución:**
- **Directo:** Capacitación in-situ al equipo comercial y de almacén.
- **Plataforma:** Google Sheets (existente, acceso fácil). |
| **6. Estructura de Costos** | - Licencias Google Workspace (si no está disponible). `evidencia`
- Tiempo de configuración y capacitación inicial. `hipótesis`
- Mantenimiento y soporte (interno). `hipótesis` |
| **7. Fuentes de Ingresos** | N/A (Proyecto interno académico sin cobro directo) |
| **8. Métricas Clave** | - **Criterio de éxito (profile):** Usuario planta/almacén responde “¿hay talla X en Y?” con fuente de cierre de turno; % descuadre medido en muestra. `evidencia`
- % de exactitud de inventario (declarado vs físico). `hipótesis`
- Tiempo promedio de respuesta para consulta de stock. `hipótesis` |
| **9. Ventaja Especial** | Ninguna aún (se construirá con el tiempo al generar disciplina operativa y datos de campo). |
