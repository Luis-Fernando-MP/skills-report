# Perfil del proyecto

## Tema
Alertas de stock mínimo para ferretería pequeña (PoC académico)

## Descripción
Propuesta de MVP académico: catálogo acotado (50–100 SKUs), umbrales de stock mínimo y lista de reposición semanal, inspirado en necesidades de ferreterías de barrio. El referente de mercado **Pulpos** (software de gestión/POS para ferreterías) se usa solo como ancla de contexto competitivo público, no como auditoría AS-IS interna ni partnership.

## Problema identificado
Las ferreterías pequeñas operan inventario a ojo: quiebres de SKUs de alta rotación y compras de emergencia erosivas. Falta un flujo simple de alertas de mínimo sin adoptar un POS/ERP completo.

## Alcance
MVP de curso (1 semestre): una tienda simulada, catálogo 50–100 SKUs, altas/bajas, umbral mínimo, lista de reposición exportable. Fuera de alcance: POS/cobro, CFDI, multi-sucursal, crédito a contratistas, IA predictiva de demanda, integración con proveedores.

empresa
